# Canonical identity

Public method overview. The unchanged original contains historical empirical
examples retained privately; those results are not included here.

Use provider IDs and explicit team/competition/season contexts. Preserve aliases without multiplying actors; do not merge ambiguous players solely by similar names. Identity validation is not publication permission.
