# Progressive passing

Public method overview. The unchanged original contains historical empirical
examples retained privately; those results are not included here.

Retain Joseph Level A geometry and open-play filters. Combine compatible raw counts and exact exposure, not club percentages or ratings. Difficulty uses an explicitly named supported whole-cohort reference; unavailable calibration remains unavailable. The proxy does not observe defenders crossed.

See [implementation or current method](fifth-attribute-progressive-passing.md),
[the current local application](unified-local-website-integration.md), and
[test inventory/private verification](test-suite-inventory.md).
