# Provisional observation metrics

Public method overview. The unchanged original contains historical empirical
examples retained privately; those results are not included here.

Validate raw observations before ratings. Align rates to supported exposure, keep action-ratio denominators separate from minutes, and preserve unavailable measurements rather than imputing zeros.

See [implementation or current method](../scripts/audit_provisional_metrics.py),
[the current local application](unified-local-website-integration.md), and
[test inventory/private verification](test-suite-inventory.md).
