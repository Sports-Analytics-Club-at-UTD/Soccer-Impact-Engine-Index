# Provisional profile contract

Public method overview. The unchanged original contains historical empirical
examples retained privately; those results are not included here.

Preserve canonical identity, context, metric support, missingness and provenance. A supported zero differs from missing data. Unsupported roles and ties remain explicit; an observation-only contract cannot fabricate ratings or a radar polygon.
